# Student Marks Calculator

A simple Python project that calculates a student's total marks, percentage, and pass/fail result.

## Features

- Enter student name
- Enter marks for 5 subjects
- Calculate total marks
- Calculate percentage
- Display PASS or FAIL

## Technologies Used

- Python 3

## How to Run

1. Open `student_marks_calculator.py`
2. Run the program using Python or Pydroid 3.
3. Enter the student's name and marks when requested.
